# Documentation

Active docs are intentionally short and manual-run focused.

- [WANDB.md](WANDB.md): minimal W&B logging contract.
- [MANUAL_METRICS.md](MANUAL_METRICS.md): where to find per-run metrics and how
  to manually calculate AUROC, confusion matrices, and error examples.
- [ADDING_METHOD.md](ADDING_METHOD.md): how to add or adjust a method without
  reintroducing command-generation automation.

Outdated HPO, seed-batch, aggregation, and integration walkthrough docs were
removed because they described deleted automation.
